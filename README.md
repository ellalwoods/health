# Health

A symptom tracker for period cramps and everything that comes with them. It opens to today with one big button to log. You log pain first, then add only the symptom classes that happened that day (bleeding, bowel, urinary, headache, nausea, heart, sleep, and so on), so there are no empty columns. There's a calendar view, and an export to a spreadsheet for the doctor. It will sync through Supabase with the same name-and-picks login as DuoVino, DuoLogo and DuoDisco.

Status: **design stage.** Nothing is built yet.

- `design/concepts.html` (screenshot: `design/concepts.png`): eight names and three directions (Twinge, Ebb, Flare), each as Today, Log, Calendar and Export screens.
- `design/logins.html` (screenshot: `design/logins.png`): five login ideas. Tap to try them.

Open either file in a browser. All data in the mockups is made up. This repository is public, so real symptom logs never go in it: they live only on the device and in Supabase.
