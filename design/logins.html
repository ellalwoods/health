Login ideas

The same coded login as DuoVino, DuoLogo and DuoDisco: on first launch, on each device, you type your name and make a few picks. The same name and picks open the same log everywhere. Only a scrambled code (a SHA-256 hash) made from them is sent to Supabase, so your name and picks never leave the phone. No unlocks or rewards this time. Each idea is themed to one of the directions, but any of them can be restyled to fit whichever look you choose. Tap to try them.

Like the other apps, this isn't a password. It keeps your data separate rather than locked away, which is the right level for a personal log. If you'd like it to be harder to guess (it's health data), we could add a 4-digit PIN to any of these, still hashed on the phone.
